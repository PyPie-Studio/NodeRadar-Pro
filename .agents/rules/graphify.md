# Graphify Knowledge Graph Rule

## Usage
- The codebase AST knowledge graph provides instant architectural discovery of symbol relations, callers, and class dependencies.
- Re-run `graphify update .` whenever new core engines or UI pages are added to keep `graphify-out/graph.json` in sync.
- Query graph nodes and community reports before performing sweeping refactors of `SubnetScanner.cs` or `LocalDatabase.cs`.
