# superpowers-brainstorm

## Purpose
Exploratory design thinking before coding. Brainstorm for non-trivial features or refactors.

## Output Format
1. Goal
2. Constraints
3. Known Context
4. Risks
5. Options (2–4 options with pros/cons)
6. Recommendation
7. Acceptance Criteria
