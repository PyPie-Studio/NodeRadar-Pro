# ponytail

## Principles
1. **YAGNI**: Question whether speculative abstractions or features need to exist at all.
2. **Native / Stdlib First**: Use .NET 10 standard library and built-in Win32 APIs before importing external NuGet dependencies.
3. **Shortest Working Diff**: One clean, readable method over five layered abstractions.
4. **Delete Bloat**: Remove unused code proactively.
