# humanizer

## Rules
1. **No Significance Inflation**: Avoid "game-changing", "crucial", "vital", "comprehensive ecosystem", "meticulously crafted".
2. **No Em-Dash Overuse**: Replace excessive dashes with simple periods or commas.
3. **Concise Technical Focus**: State facts, file names, lines, and exact commands directly.
4. **No Sycophancy**: Do not praise or flatter in responses. Be direct and precise.
