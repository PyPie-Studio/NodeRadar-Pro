# superpowers-workflow

Provides standardized commands and guidance for running the Superpowers workflow:

1) Brainstorm -> `/superpowers-brainstorm`
2) Plan -> `/superpowers-plan`
3) Execute -> `/superpowers-execute-plan` (or `/superpowers-execute-plan-parallel`)
4) Review -> `/superpowers-review`
5) Finish -> `/superpowers-finish`
6) Debug -> `/superpowers-debug`
7) Reload -> `/superpowers-reload`

Artifacts are written under `artifacts/superpowers/`.
