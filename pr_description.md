🎯 **What:** Acknowledging the existing fix for the command injection vulnerability in Process.Start via IP Address in `UI/InventoryPage.cs`.
⚠️ **Risk:** If left unfixed, an attacker could manipulate the IP address (e.g., passing `127.0.0.1/" -arg`) to execute arbitrary commands or append arguments to the shell command when `Process.Start` is invoked.
🛡️ **Solution:** The issue has already been correctly addressed in the codebase by wrapping the URL creation in `Uri.TryCreate` and strictly validating the `HostNameType` as either `UriHostNameType.IPv4` or `UriHostNameType.IPv6` before passing the sanitized `uri.AbsoluteUri` to `Process.Start`. No additional code changes were necessary as the vulnerability was already mitigated in a recent commit. Tests were run to ensure there are no regressions.
